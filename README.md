# 第一性原理·轻量化永动知识图谱Agent

## 项目简介

本项目基于第一性原理设计，构建一套零依赖、轻量化、永久自治、自主进化的智能体系统。摒弃传统定时任务、人工投喂任务、外部调度的模式，实现：**知识驱动任务、任务沉淀知识、系统永续运行、自主迭代升级**。

## 核心设计原则

### 三大公理

1. **存续公理** - 系统运行闭环永不终止，局部异常永远不能击穿整体系统
2. **记忆公理** - 智能体的智能 = 结构化、可沉淀、可关联、可检索、可推演的历史经验
3. **自驱公理** - 无外部输入时，系统必须自我产生任务、自我梳理知识、自我精简迭代

### 系统架构（三层极简单向依赖）

- **存续保活层（底层）** - 负责系统永久在线、异常隔离、资源管控、自愈恢复
- **知识记忆层（中层）** - 以轻量化知识图谱为核心，存储实体、关系、权重，沉淀所有运行经验
- **自驱进化层（上层）** - 基于图谱关联关系自动生成新任务、空闲自动复盘、自动精简知识、迭代优化权重

### 轻量化约束

- 零外部服务依赖（无数据库、无Redis、无MQ、无Neo4j服务、无容器依赖）
- 全本地文件持久化（断电、重启、崩溃不丢失记忆）
- 无冗余逻辑（所有代码可被三大公理解释）
- 低资源稳态运行（空闲极低负载，运行高内聚）
- 完全自闭环（无需人工干预、无需外部API持续输入）

## 快速开始

### 启动系统

```bash
python3 main.py
```

### 使用知识图谱

```python
from models.knowledge_graph import KnowledgeGraph

# 创建知识图谱
kg = KnowledgeGraph()

# 添加节点
kg.add_node('任务A', 'TASK')
kg.add_node('任务B', 'TASK')

# 添加边
kg.add_edge('任务A', '任务B', '衍生', 0.8)

# 推演新任务
tasks = kg.derive_new_tasks('任务A')
print(tasks)
```
